# Aula 06 — Dados, armazenamento e sistemas de arquivos

Esta pasta é independente: mantenha juntos `index.html`, `aula.css` e `gifs/`.

## Validação local

Abra a pasta com o Live Server no VS Code e acesse:

`http://127.0.0.1:5500/aula06-dados-e-armazenamento/`

## Publicação

Copie a pasta inteira para a raiz do repositório. A URL resultante será:

`https://procristianopessoa.github.io/sistemasoperacionais/aula06-dados-e-armazenamento/`

O arquivo `gerar_animacoes.py` permite regenerar os cinco GIFs com Python e Pillow.
