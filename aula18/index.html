Seção 2 · Redes Windows Server · Aula 18

Active Directory e políticas de grupo

Em preparação · Planejamento da aula

Organizar domínio, usuários, grupos e políticas para estações.

Objetivo de aprendizagem

Ao final da aula, o estudante deverá conseguir: organizar domínio, usuários, grupos e políticas para estações.

Roteiro proposto

  1. Retomar os conceitos de sistema operacional relacionados ao tema.
  2. Observar o cenário e identificar configurações, serviços e dependências.
  3. Comparar uma situação funcional com uma falha de rede.
  4. Registrar evidências e justificar o diagnóstico.

Laboratório proposto

Modele uma estrutura de unidades organizacionais, grupos e uma política de laboratório, incluindo critérios de validação.

Ambiente: máquinas de laboratório ou máquinas virtuais em rede isolada. As instruções práticas serão adicionadas na versão completa.

Entrega e verificação

Produza um relatório com topologia, observações, evidências dos testes e conclusão. Explique a relação entre rede, serviços e controle de acesso no sistema operacional.
