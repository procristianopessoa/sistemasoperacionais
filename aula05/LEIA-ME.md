# Aula 03 — Sistemas de Arquivos

## Conteúdo do pacote

- `index.html`: aula interativa completa.
- `gifs/`: seis GIFs usados pela aula.
- `gerar_gifs.py`: fonte dos GIFs, para revisão ou regeneração.

## Publicação no repositório

Copie a pasta `aula03-sistemas-arquivos` para a raiz do repositório. A URL será:

`https://procristianopessoa.github.io/sistemasoperacionais/aula03-sistemas-arquivos/`

No PowerShell:

```powershell
git add aula03-sistemas-arquivos
git commit -m "Adiciona aula sobre sistemas de arquivos"
git push origin main
```

## Escopo pedagógico

Inclui persistência, caminhos, diretórios, inodes, blocos, redirecionamento, cópia, movimentação, comparação, remoção, permissões, propriedade, espaço e montagem. Não executa `sudo`, `rm -rf`, alteração de partições ou formatação de discos.
