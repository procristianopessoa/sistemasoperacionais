AULA INTERATIVA · SISTEMAS DE ARQUIVOS

Dados só se tornam memória coletiva quando o sistema sabe onde encontrá-los.

Arquivos não são apenas sequências de bytes. São nomes, caminhos, metadados, permissões e blocos de armazenamento organizados para que aplicações e pessoas possam recuperar informação com segurança.

01 · O PROBLEMA DA PERSISTÊNCIA

Um processo termina. O dado não deveria terminar com ele.

O papel do sistema de arquivos

A memória RAM permite que um programa trabalhe rapidamente, mas é volátil. Quando o processo encerra ou a máquina desliga, o sistema operacional precisa de uma estrutura persistente para guardar, localizar, proteger e compartilhar os dados.

O sistema de arquivos é esse contrato entre aplicações, pessoas e dispositivos de armazenamento.

1
Nomear
Um arquivo precisa ser reconhecido por um nome dentro de um diretório.
2
Localizar
O caminho conduz o sistema por uma árvore de diretórios.
3
Descrever
Metadados registram tamanho, datas, dono, permissões e referências aos dados.
4
Persistir
Blocos no dispositivo armazenam efetivamente o conteúdo.

02 · CAMINHOS, DIRETÓRIOS E INODES

O caminho é uma rota lógica; o inode descreve o arquivo encontrado.

Quando você solicita /home/aluno/projeto/notas.txt, o Linux não procura um texto gravado diretamente nesse nome. Ele percorre diretórios, consulta associações entre nomes e inodes e, por fim, encontra os blocos de dados.

Diretório

É uma estrutura que associa nomes a referências. Um diretório não é apenas uma “pasta visual”: ele ajuda o sistema a descobrir qual inode corresponde a cada nome.

Inode e blocos

O inode registra metadados e referências aos blocos. Por isso, nome, metadados e conteúdo podem ser entendidos como elementos relacionados, mas distintos.

04 · ESPAÇO E MONTAGEM

O usuário vê uma árvore única; o sistema pode usar vários volumes.

df -h .

Mostra a capacidade, a ocupação e o espaço disponível no sistema de arquivos montado no caminho informado.

du -sh projeto

Mede o espaço ocupado por uma árvore específica de diretórios e arquivos.

07 · DESAFIO CONTEXTUALIZADO
Audite o pequeno projeto de uma equipe.
Você recebeu um diretório com anotações e precisa demonstrar como o Linux organiza esses dados. Use a área criada no laboratório e registre evidências, não apenas comandos.

  2. Crie uma cópia de notas.txt, altere a cópia com >> e compare os dois arquivos com diff.
  3. Use stat para identificar os metadados de um arquivo.
  4. Use find para localizar os arquivos de texto.
  5. Informe o espaço usado pelo projeto com du -sh e o espaço disponível no sistema de arquivos com df -h ..
