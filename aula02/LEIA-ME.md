# Aula 04 — Processos e Escalonamento

Este pacote deve ser mantido com sua estrutura de pastas:

```text
aula04-processos-pacote/
├── index.html
└── gifs/
    ├── 01-fila-prontos.gif
    ├── 02-politica-decide.gif
    ├── 03-fifo-efeito-comboio.gif
    ├── 04-sjf-menor-burst.gif
    ├── 05-round-robin-quantum.gif
    └── 06-comparar-metricas.gif
```

Para o GitHub Pages, envie a pasta inteira para o repositório, por exemplo em
`aula04/`. O endereço publicado será então:

`https://procristianopessoa.github.io/sistemasoperacionais/aula04/`

No Moodle, use a URL publicada em um iframe. Os GIFs fazem parte da página e
não precisam ser inseridos separadamente no Moodle.
